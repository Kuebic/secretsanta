# Domain docs

Single-context repo.

- `GLOSSARY.md` at the root is the vocabulary. Read it before naming anything; use its terms and avoid the listed alternatives.
- `docs/adr/NNNN-slug.md` records decisions. Read the ones in the area you touch before changing it; do not silently contradict one. Add a new ADR only for a hard-to-reverse, surprising, trade-off decision.
